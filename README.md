# Ядро для интернет-магазина

## Описание:
Данная программа в стадии разработки и будет дополнятся новым функционалом. Программа пишется на Python.
На данный момент работает 4 блока:
* Класс для продуктов
* Класс для категорий товаров
* Открытие JSON-файл
* Создание списка из набора данных по категориям и товарам

## Установка:

1. Клонируйте репозиторий:  

```shell  
   git clone https://github.com/Alex-L11/Home_work_14.1.git
```
2. Установка зависимости:
```
pip install -r requiremenys.txt
```

## Использование: 

1. Откройте PyCharm
2. В окне нажмите New project
3. В терминале введите команды из "Установка", пункты 1 и 2
